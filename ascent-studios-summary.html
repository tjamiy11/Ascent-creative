1. What this is

Ascent Studios is the marketing website for a Chicago-based video & photography studio (founder: Stefan, IG @uglysteffy). It is an editorial, motion-forward portfolio site: a kinetic hero, a portfolio/work grid of 53 projects, per-project case-study pages, an about page, a testimonials page, and a contact page.

4. Cloudflare R2 — the video CDN

Cloudflare R2 is the only third-party service the running site depends on. All video playback is served from a single public R2 bucket; no Cloudflare Workers, Pages, or Images product is used — just R2 object storage exposed over its public r2.dev URL.

ItemValue
Public bucket URLhttps://pub-1782b44702d746a7a6cc86a019b0fb9f.r2.dev/
Hosts1 hero reel (hero.mp4) + 24 project clips (hoka, dtlr, palmer, samsung, ducati, lollareverb, croatia, missusa, blum, trulli, candycloud, morph, halogram, giftcard, teaser, boxed, multiple, sonim, jordan-pele, dreamy, nick-blum, uglysteffy, vespa, adidas-macys)
Referenced inlib/projects.ts (24 clip: URLs) & components/hero-reel.tsx (hero source)
Why R2mp4s are multi-MB each; keeping them out of git/Vercel avoids repo bloat and deploy-size limits. R2 has zero egress fees.
How a video gets added: transcode .mov → small .mp4 (ffmpeg -i in.mov -c:v libx264 -crf 24 -vf "scale=1280:-2" out.mp4), upload the mp4 to the R2 bucket, set clip: to the R2 URL in lib/projects.ts, and drop a first-frame .jpg cover into public/video/. The repo never stores the mp4.

5. Vercel — hosting & deploy

  • Project: ascent-studios (linked via local .vercel/project.json).
  • Deploy trigger: every push to main on GitHub auto-deploys to production at ascentstudios.co.
  • Environment variables: none required — video URLs are hardcoded.
  • Build: next build (default). Image optimization runs on /public covers, logos, and photos.
  • Deploy hygiene: .vercelignore excludes the local raw-media working folders (/Videos/, /Photos/, /Thumbnails/, /company logos/) and all public/video/*.mp4 so multi-GB sources never upload. A case-insensitivity quirk that previously broke deploys is documented in the file.
